Kesher

Kesher means connection. It's a hosted meeting app built around one idea: a shared whiteboard, chat, polls, reactions, and a host who can hand off the room — in one screen, not five tabs.

About

One room, one host, everyone on the same page

Kesher is built for sessions that need more than a video feed — classes, workshops, team reviews, study groups. One person hosts and can pass hosting to someone else mid-session. Everyone else joins as an attendee, sees the same whiteboard, and can react, chat or vote in a poll without leaving the call.

Kesher is live on the web today, with native iOS and Android apps in active development from the same codebase — built to feel identical whether a session is joined from a laptop or a phone.

Inside a session

What it actually looks like

Start when you're ready

Every session gets a join code and a lobby. The host can start the moment the room is ready, or let a timer count down while people join.

Everything in one screen

Mic, camera, screen share, board, polls, a timer, chat, reactions and co-host controls all sit in one bar — nobody's hunting through menus mid-session.

A real whiteboard, not a screenshot of one

Pen, highlighter, shapes, a laser pointer for walking through a point live, undo and redo. Boards can be locked so only the host draws, or opened up to the room.

Chat that runs alongside the call

Side conversation, quick reactions, and a record of what was said — without switching out of the session to a separate app.

Hosting, shared on purpose

A co-host can mute people, bring someone to the board, or remove an attendee — but can't end the session or hand out further co-host roles. Control stays clear even when it's shared.

A clean wrap-up

When a session ends, everyone gets a summary — duration, who was there, and the session code — with a link through to anything submitted during the session.
